# Настройка трёх машин (масштабируется без изменений кода)

Главный физический склад: **Береке базар** (`MOYSKLAD_WAREHOUSE_ID`).

В интерфейсе МойСклад вручную создайте три склада:
- Машина №1
- Машина №2
- Машина №3

Каждый склад представляет остатки товара в соответствующей машине. Все три получают товар из одного склада «Береке базар». При дозагрузке оформляется ещё одно перемещение из «Береке базар» в машину; при необязательном возврате — обратное перемещение. При продаже товар уходит из остатков склада машины. Остатки не возвращаются автоматически при закрытии смены.

## Привязка продавцов

В Vercel Environment Variables задайте `MOYSKLAD_VEHICLE_WAREHOUSES` в виде JSON:

```json
{
  "SUPABASE_USER_UUID_1": "MOYSKLAD_STORE_UUID_MACHINE_1",
  "SUPABASE_USER_UUID_2": "MOYSKLAD_STORE_UUID_MACHINE_2",
  "SUPABASE_USER_UUID_3": "MOYSKLAD_STORE_UUID_MACHINE_3"
}
```

Замените все заглушки на реальные UUID. Не копируйте пример как готовое значение.

Когда появится четвёртая машина, создайте ещё один склад и добавьте четвёртую пару UUID в переменную окружения — количество машин в коде не ограничено.

**Важно:** PR не создаёт склады автоматически и не меняет остатки в МойСклад. Перед включением реальных операций потребуется подтверждённая привязка машин, серверная авторизация и защита от повторного проведения документов. Если продавцы могут менять машины, нужно заменить привязку по user UUID на явное назначение машины на смену.
